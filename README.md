# One-Line Roast: The Gadget You Use Every Day

**The line (116 characters):**

> My smart kettle needs a firmware update before it will boil water, so I stand there thirsty while it learns to boil.

## Why it wins on the judge's 5 criteria

1. **Daily gadget, named** — a smart kettle, used every day, is the target from word one.
2. **Actually funny** — the absurdity lands on first read: a kettle that cannot do the single thing it was bought for until it updates itself, and the owner standing there thirsty.
3. **Fresh** — not the obvious complaint. The kit's own examples name the rating-popup app and the dying phone battery; this entry avoids both. A kettle "learning to boil" is an angle nobody has roasted before.
4. **Neatly worded** — 116 characters, comfortably inside the 200 cap, no wasted words; the punch ("learns to boil") lands on the last three words.
5. **One person's specific gripe** — a concrete, real behavior: smart kettles really do gate boiling behind firmware updates. Not a generic complaint that could be about anything.
